# Student Lifestyle and Academic Performance Analysis

This project is an exploratory data analysis (EDA) examining how various student lifestyle factors correlate with academic success (CGPA).

## Key Insights
* **Sleep Quality:** There is a positive correlation between sleep quality and academic performance (CGPA).
* **Part-Time Jobs:** Analyzing the impact of part-time employment shows a slight positive trend in overall grade distribution, challenging the common assumption that working part-time hinders academic success.

## Tools & Libraries Used
* Python
* Pandas
* Seaborn / Matplotlib
* Google Colab
